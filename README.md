# FEIT Global landing

Static landing page for `feitglobal.com`.

## Files

- `index.html` - page markup
- `styles.css` - responsive styling
- `script.js` - language switcher, theme switcher and inquiry form mailto logic
- `assets/feit-logo-gold.png` - FEIT logo with transparent background
- `assets/grain-terminal-hero.webp` - grain field / terminal hero visual
- `assets/uae-trade-hero.webp` - previous UAE/global trade visual kept as a backup asset
- `assets/dubai-office-network.webp` - Dubai office/network visual

## Current note

The landing supports English and Russian versions in one file, plus dark and light themes.

## First publication option

The page does not require a VPS. It can be published as a static site on any hosting that serves plain HTML files.

Upload the contents of this folder to the website root. The entry file is `index.html`.

## Form behavior

Until a backend is connected, the inquiry form opens a prepared email to `info@feitglobal.com`.
